## 恢复状态与准入结果

恢复状态定义为：相对当时历史最高收盘仍至少低 20%，同时从过去 52 周最低收盘至少反弹 20%；趋势状态另按最近完成周的 50 周均线及斜率划分。定义固定，没有为本次 BTC 上涨重新调参。

BTC 的 90 / 180 / 365 天，恢复状态和其他状态都未通过：候选 Brier、logloss 和分位数误差均逊于同信息集的无条件基准。恢复状态的 Brier 改进分别为 −0.00246 / −0.00491 / −0.02424；负值代表变差。BTC 365 天的 80% 区间实际覆盖仅 66.1%。

ETH 三个期限的恢复状态也都未通过；180 天虽有微小 Brier 改善，logloss 仍变差。365 天仅有 5 个互不重叠的结果窗口，未达到工程支持量要求。每个资产与期限的全部失败原因均保留在下方 JSON 的 gates 字段，不能只挑选表现较好的期限。

## 输入与证据边界

采用与主看板相同的生产价格输入：BTC 从 2014-09-17 起，ETH 从 2017-11-09 起，均截至 2026-09-24。使用归档与价格补充源拼接后的日收盘，不另外前向填充缺失日期；缺口会减少可训练样本。预测锚点不包含实时盘中报价，也不验证盘中最低价。

本报告在 2026-09-25 的数据快照上重建历史预测。每次拟合只使用当时已成熟且经过 28 天缓冲的结果，但数据本身可能后来修订，研究者也已经知道历史走势。因此，时间顺序正确的历史重建仍不能证明未来可靠。

未来的预测账本（ledger）需要按真实发布时间保存当时输入、模型版本、概率和锚点，等待各自期限到期后再评分。该账本与本报告的历史重建样本必须分开统计；现有报告没有提供新模型已经完成的前瞻验证。

更长 CoinMetrics 历史作为单独的敏感性检查也未通过：BTC 和 ETH 的三个期限 Brier 均逊于各自基准。主报告仍采用实际生产输入，避免将不同来源、不同历史长度的结果当成主看板验证。
